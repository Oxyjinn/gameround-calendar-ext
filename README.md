# Gameround Calendar
Scraping G.Round Test Info and adding it to your personal Google Calendar. Making sure you don't miss the test date.

How to use:
1. Code -> Download ZIP.
2. Unzip the folder.
3. Go to your browser and click manage extensions.
4. Activate "developer mode".
5. Click "Load unpacked" and choose your folder.
6. Enjoy the extension.

How it works:
1. Go to your specific g.round test page (example: https://gameround.co/detail/1/info).
2. Click the g.round extension (Win shortcut: Alt+Shift+G / Mac shortcut: Command+Shift+G).
3. Finish your google calendar event. 

Tested on Chrome & Edge.
